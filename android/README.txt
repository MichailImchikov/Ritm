РИТМ ДЛЯ ANDROID 1.0 — задачи и планы на телефоне Samsung Galaxy

ЧТО ЕСТЬ
«Мой день»: приветствие, прогресс дня, график недели и серия дней, таймер фокуса 25/5 с привязкой к задаче, просроченные и сегодняшние задачи.
«Задачи»: доска (К выполнению / В работе / Готово — вкладки со свайпом) или список с группами (Просрочено, Сегодня, Завтра, Ближайшие 7 дней, Позже, Без даты, Выполнено). Фильтр по проектам, поиск, выбор вида запоминается для каждого проекта. Карандаш в заголовке проекта — переименовать или удалить.
«Календарь»: месяц и неделя, свайп влево/вправо листает, точки задач по приоритетам; «Задача» создаёт дело на выбранный день.
Карточка: кружок — выполнено (с «Отменить»), тап — форма задачи, долгое нажатие или ⋯ — статус, «На сегодня», «На завтра», «Через неделю», «Выбрать дату…», «Фокус на задаче», «Дублировать», «Удалить».
Умный ввод, как на компьютере: «Позвонить маме завтра !1 #Личное».
Уведомления: утренний «План на день» (время настраивается), сигнал окончания фокуса/перерыва, отсчёт таймера в шторке.
Виджет «Ритм · Мой день» (4×2, размер меняется): задачи на сегодня и просроченные, кружок отмечает выполненной, «+» — быстрая задача.
Ярлыки на иконке (долгое нажатие): «Новая задача», «Фокус».
Темы: как в системе / светлая / тёмная и пять палитр десктопа — Ирис, Океан, Шалфей, Янтарь, Пудра.

УСТАНОВКА НА ТЕЛЕФОН
Файл: outputs/Ritm-Android/Ritm.apk.
Вариант 1 — по кабелю: на телефоне «Настройки → Сведения о телефоне → Сведения о ПО», 7 раз нажать «Номер сборки»; затем «Параметры разработчика → Отладка по USB». Подключить кабель и выполнить:
  %LOCALAPPDATA%\Android\Sdk\platform-tools\adb.exe install -r outputs\Ritm-Android\Ritm.apk
Вариант 2 — файлом: скопировать Ritm.apk на телефон (кабель, Quick Share, облако), открыть в «Мои файлы» и разрешить установку из этого источника.
При первом запуске разрешите уведомления. Чтобы Samsung не задерживал напоминания: «Настройки → Приложения → Ритм → Батарея → Без ограничений». Для точного сигнала таймера в настройках Ритма нажмите «Разрешить точные будильники» (если кнопка есть).

СИНХРОНИЗАЦИЯ С КОМПЬЮТЕРОМ (Google Диск)
Телефон использует ту же скрытую папку приложения на Google Диске, что и Ритм для Windows. Для этого в Google Cloud нужен ещё один OAuth-клиент — типа Android — в ТОМ ЖЕ проекте «Ритм», где создан клиент Desktop app:
1. https://console.cloud.google.com/apis/credentials → выберите проект «Ритм».
2. «Create credentials → OAuth client ID», тип «Android».
3. Package name: ru.ritm.planner
4. SHA-1: 83:50:70:A6:67:B7:57:87:77:A0:E3:D3:D5:0D:E2:C5:3C:37:B8:5B
5. Сохранить. Скачивать JSON не нужно.
6. Если OAuth-экран в режиме Testing — ваш аккаунт Google должен быть в списке Test users (он уже там, если вход работает на компьютере).
7. На телефоне: «Настройки → Google Диск → Войти через Google».
После входа синхронизация идёт при открытии приложения, через несколько секунд после каждого изменения и раз в 15 минут в фоне. Конфликты решаются как на компьютере: побеждает более поздняя правка, прежние версии сохраняются в истории.

ДАННЫЕ
Задачи хранятся в памяти приложения (по файлу на запись, как на компьютере). Экспорт/импорт JSON в «Настройки → Данные» совместим с Ритмом для Windows.

СБОРКА
Исходники: work/android. Нужны Android SDK (%LOCALAPPDATA%\Android\Sdk) и JDK из Android Studio.
  set JAVA_HOME=C:\Program Files\Android\Android Studio\jbr
  gradlew.bat testDebugUnitTest assembleRelease
Готовый файл: app/build/outputs/apk/release/app-release.apk.
Ключ подписи: work/android/ritm-release.jks, пароли — в keystore.properties (оба файла не попадают в git). Сохраните их копию: обновлять установленное приложение можно только APK, подписанным тем же ключом, и SHA-1 OAuth-клиента привязан к нему.
Можно открыть папку work/android в Android Studio.

ПРОВЕРКИ
Модульные тесты (7): умный ввод (даты, дни недели, приоритет, проект), версии и конфликты хранилища, проекты (переименование, удаление), чтение JSON десктопа, таймер фокуса, обмен через Google Диск между двумя «устройствами» на поддельном сервере (создание, правка, удаление, отсутствие повторных загрузок, проверка целостности).
